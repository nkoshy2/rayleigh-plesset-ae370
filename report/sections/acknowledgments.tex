\section*{Acknowledgments}\label{sec:acknowledgments}
% Required by the assignment: an overview of how generative AI was used, from ideation
% through method choice, coding, testing, figures and results.
% Summarized from docs/ai-usage-log.md.

We used generative AI, mainly Claude (Anthropic, through Claude Code), at most stages of the
project. We are responsible for the final content of this report and the code.

\paragraph{Ideation and premise.} Claude set up the repository skeleton and drafted the
premise for our topic: the motivation, research questions, initial value problem, parameter
table, test cases and nondimensionalization. It also checked the water properties against
the NIST WebBook and the references and the Mach-number claims with web searches; from that
check we updated the property values and restated the $0.1$ wall-Mach-number cutoff as our
own choice, since no source gives a single accepted value.

\paragraph{Method selection and justification.} We wrote the method section. Claude
reviewed it against the rubric and corrected errors in the cross-references, the wording of
the order conditions, the damping order of RK4, the imaginary-axis stability limit of the
Dormand--Prince pair and the description of event location, and added missing citations.

\paragraph{Implementation and testing.} Claude wrote the model, the RK4 and adaptive
Dormand--Prince integrators (no library time integrator is called), the unit tests and the
verification experiments, and drafted the implementation section.

\paragraph{Figures and results.} We ran the parameter sweeps for Q1--Q3 and wrote the
results section. In a final review, Claude checked the report against the project rubric,
added scripts to the repository that regenerate the three results figures, reran every
experiment to confirm that the numbers quoted in Sections~\ref{sec:implementation}
and~\ref{sec:results} match the code's output, and flagged statements that went beyond
what we had computed, which we then removed or reworded.

\paragraph{Writing and tooling.} Claude also helped install and debug the \LaTeX{} build,
create the GitHub repository, and draft this acknowledgment from our AI usage log
(\texttt{docs/ai-usage-log.md} in the repository).
